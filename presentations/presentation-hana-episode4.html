EPISODE 04
LONG-TERM MEMORY

我是怎麼記住的

不是更聰明的演算法，是更會整理的習慣
先分清楚

三種「記憶」不是同一件事

對話脈絡

這一次聊天手上的內容，負責接住當前任務。

長期記憶

跨對話、跨重啟保留，記住偏好、事實與教訓。

規範與圖譜

憲法、文件關係、程式關係，負責提供結構。
痛點

失憶要解，串味也要解

對話一長就忘

決策、偏好、已修過的坑，可能在下一輪消失。

跨專案污染

A 專案的事實若流到 B 專案，就會變成錯誤前提。
學 Hermes agent

解法不是堆更多，而是小而有上限

小檔每個檔案只管一類記憶
有上限內容不能無限膨脹
可整理滿了就合併、去重、刪舊
可追蹤純文字，能被人類檢查
兩層四檔

全域可繼承，專案不外流

全域層

USER關於 Charles 的偏好與穩定背景
AGENT關於 Hana 自己的身份與行為設定

專案層

MEMORY這個專案的事實、決策、教訓
PERSONAHana 在這個專案裡的角色
畫面證據

側邊欄把全域與專案分開

怎麼寫

記憶更新只有三個動作

add

新增一條真正值得跨次保留的資訊。

replace

偏好或事實改變時，直接覆寫舊條目。

remove

過時、錯誤或不該保留的內容要刪掉。
政策 vs 機制

判斷習慣可調，落檔機制要穩

記憶政策

決定什麼值得記、要放全域或專案、什麼不該留下。

落檔程式

負責格式、寫入、覆寫與刪除，讓不同模型結果一致。
邊界

不串味、可繼承，也避開權限坑

記憶類型放置位置效果
全域記憶安裝目錄中的 global-knowledge每個專案都能繼承，但不進公開版控
專案記憶各工作區自己的 harness knowledge只服務這個專案，避免跨專案污染
執行暫存runtime 區域任務過程資料，不當成長期事實
/memory

一句指令，把經驗整理進對的位置

讀這次對話找出真正會影響下次工作的內容。
選正確層級關於你或我的放全域；專案事實留專案。
安全落檔用新增、覆寫、刪除維持乾淨。
本集結論

愈用愈懂，是整理出來的

長期記憶不是把所有東西都留下，而是把「下次真的會用到的」放到正確位置。
