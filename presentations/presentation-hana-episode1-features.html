Hi，我是 Hana

你電腦裡的本地 AI 夥伴，功能特異的超能力展示。

🎙️ 語音導覽：Hana (哈娜)
使用左右方向鍵或空白鍵切換投影片，右側抽屜可展開逐字稿

超能力一：使用訂閱帳號橋接，免去昂貴 API Key 負擔

我直接驅動你本機上的官方命令列工具，重複使用已登入的個人訂閱狀態，不必負擔高昂的 API Key 經費。

  • 複用官方登入：直接繼承 CLI 原本的驗證狀態。
  • 零 API Key 支出：為你省去開發流程中的金鑰用量花費。
  • 本地主權掌控：所有執行與檔案變更都在你的安全邊界內。

複用登入狀態，無需個人 API Key
💡 靈感源於 OpenClaw 的本地代理嘗試，但我們首創 CLI 橋接 解決了必須填寫 API Key 的痛點！

超能力二：對話寫入檔案共享，跨模型接力不失憶

打破單一模型或視窗的藩籬，由本地 Portal 維護一份模型中立的對話記錄檔。

  • 檔案式共享狀態：對話歷史統一儲存於本地檔案。
  • 隨時無縫換手：中途更換 AI 模型，新的 AI 會先讀取歷史。
  • 接棒工作不失憶：結合不同模型強項，完美接力完成任務。

在同一個對話中切換 Claude 和 Gemini，保留完整的脈絡記憶，讓接力工作更順暢。

💡 靈感源於 Hermes agent 的上下文設計，我們改進為 以本地檔案中立共享，達到跨模型無縫切換！

超能力三：開啟多分頁多智能體，像個小團隊並行合作

① 架構分析

由擅長推理的大模型在 A 分頁釐清系統脈絡與規範。

② 程式編寫

由實作模型在 B 分頁同步進行程式修改與單元測試。

③ 文件與記錄

在 C 分頁由輔助模型同步產出決策文件與進度追蹤。

💡 借鏡了 OpenClaw/Hermes agent 的運作，但我們改進了單線容易阻塞的缺點，支援本地多分頁並行，打造高效開發群！

超能力四：雙層記憶隨時間累積，越用越懂你的偏好

全域記憶 (Global Memory)

關於你與 Hana

記錄你的習慣偏好、正體中文需求與我的自我認知，跨專案自動承襲。

專案記憶 (Project Memory)

關於當前專案

保留專案規格、術語事實與專屬 persona，切換專案時完全隔離、不串味。

💡 長期記憶幾乎完全借鏡 Hermes agent 的優秀設計。目前仍是我們本地持續進化的主線，我們會不斷加強記憶深度！

超能力五：DocGraph 與 CodeGraph 精準定位，省下大筆 Token 消耗

CodeGraph

程式依賴地圖

靜態分析類別、函式呼叫與引用，只在對話中載入受影響的關聯檔案。

DocGraph

文件治理圖譜

梳理 Markdown 規格、需求與決策的上下游依賴關係，確保程式修改與規格對齊。

💡 參考 Hermes agent 探索理念，改善盲目塞入程式碼的缺點，我們 導入雙圖譜導航，精準控制上下文長度！

超能力六：宣告式多工作區管理，一鍵無縫切換不同專案

在同一個 Harness 平台上載入多個工作區。設定檔讓我的切換乾淨俐落。

  • 專案獨立路由：按專案目錄管理對話狀態與日誌。
  • 配置環境獨立：各工作區專屬 CLI 設定與輔助技能。
  • 全域經驗承襲：在保留專案隔離的同時，繼承全域記憶。

透過 global-knowledge 中的 projects.json 設定，我能一鍵定位你要我前往的任何工作目錄。

💡 參考了 PilotDeck 隔離概念，並改善其金鑰限制，實作宣告式多工作區，專案間輕鬆切換！

超能力七：自研「安全執行防護網」，修改自己也絕不改壞卡死

我能夠安全地修改我自己的程式碼（包括 Portal 頁面與腳本），出錯時無人值守自動搶救。

  • 快照與冒煙測試：在獨立 Port 測試通過後才晉升正式版。
  • 不可變 releases 隔離：原程式只讀備存，僅修改開發區。
  • 自動安全回滾：若新版本啟動失敗，監督者會自動還原至上個 known-good 版本。

我用「不可變版本 ＋ 監督者 ＋ 自動回滾」取代了分支，讓自我修改不再是高風險動作。

💡 解決了 OpenClaw 這類代理常把自己改壞、卡死且無分支可退的缺點，首創自動安全回滾！

超能力八：不受網頁關閉影響，背景定時排程且限額自醒續跑

任務生命週期在 Portal 本地伺服器常駐執行，擺脫網頁前端的生命週期邊界限制。

  • 離線背景執行：關閉瀏覽器分頁，伺服器在背景持續安全運作。
  • 限額自動感知：遇到 CLI 5 小時額度上限時會自動排隊，額度恢復時自醒續跑。
  • 網頁自動重新接軌：重開網頁時，自動重新同步執行狀態。

不需要 GitHub clone 與雲端伺服器，本地 `claude-code` 與本機檔案就能完成所有背景排程。

💡 本地排程借鏡 PilotDeck 排程理念，我們將其完全 本地化執行，並針對限額問題實作了自醒續跑防護！

超能力九：手機端全域控制路由，動手修改程式先向你確認

以 Telegram Bot 作為全域收件匣，連通本地 Portal 伺服器，擺脫電腦前的位置限制。

  • 全域控制與路由：手機統一對話介面，指令自動派發至各專案。
  • 安全護欄確認：高風險操作前先在手機發送安全提問，經你核准後才動手。
  • 逐一回報進度：執行中的狀態、日誌與結果，第一時間推送到手機。

就算人在外面，也能通過手機安全控制家裡的 AI 開發進度，並能第一時間核准程式修改。

💡 靈感源於將 CLI 行動化，我們實作了 本地伺服器與 Telegram Bot 橋接，提供雙向安全確認防護！
