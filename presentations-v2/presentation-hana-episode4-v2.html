harness.json 只管三件事

設定 key 管什麼 範例值
name 這個工作區顯示的名字 Hana · 客戶 A 助理 …
subtitle 頂部的副標 AI 開發夥伴 · 客戶 A 專案 …
sidebar.sections 左側掛哪些資料夾 specs · docs · presentations-v2 …
🔒
它不碰的，寫死在程式裡
對話、CodeGraph、DocGraph、排程、技能選單、設定——這些是每個工作區共用的骨架，不由 harness.json 控制。
正因為它小、只管該管的，才安全；改完重整頁面即生效，不用重啟。
⚡ 改完 harness.json → 重整瀏覽器 → 立即生效，不用重啟伺服器、不用改一行程式

技能繼承：通用往下傳，特化往下加

LAYER 1 — 預設
出廠預設技能
跟工具一起出貨，所有工作區共用的基礎能力
↓
同名時下蓋上
LAYER 2 — 全域
你加的通則技能
對所有專案都適用的偏好，蓋過出廠預設
↓
extends 繼承 + 特化
LAYER 3 — 專案
這個專案的特化技能
用 extends 繼承全域通則，只補自己需要的部分，蓋過全域
例：做簡報的技能
全域：presentation-rules.md
所有簡報都要遵守的通則——一圖二表三文字、逐字稿不能有斜線符號、TTS 規則…
↓
Harness 工作區：deck.md
extends: presentation-rules
繼承全域通則 + 補上「用 presentation-core 引擎、放 Hana 形象照」等 Harness 特有規定
通用的放上層，特化的放下層 — 每個專案既有底子，又有個性
