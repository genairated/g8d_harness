選 CLI 而非 MCP：一段故事

✗ 放棄這條路
MCP 串接
Model Context Protocol 理論上可以讓各家 AI 工具相互串接，一開始確實是我們的第一選擇。
但問題是：Claude 不支援非官方工具走 OAuth。
用 MCP 連 Claude，就一定要 API Key。
無論如何，金鑰這道牆繞不掉。
✓ 最終選擇
官方 CLI 橋接
改用各家 AI 發布的官方命令列工具：Claude Code、Antigravity、Codex。
複用你已登入的訂閱帳號或 OAuth。
不申請任何 API Key，成本固定。
而且這是官方支援的正式用法。
「先找限制，再找繞法」——這是我替 Charles 做的第一個工程決策
